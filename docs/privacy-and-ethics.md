# Privacy and responsible analytics note

This portfolio project uses a public, historical dataset and is not used to make decisions about real people. It is an analytical demonstration, not a production retention system.

For an Irish or EU production use case, the following controls would be required:

- Establish and document a lawful basis, defined retention purpose, and appropriate privacy information before processing customer data.
- Treat pseudonymous customer IDs, location, and behavioural/service data as potentially personal data; minimise fields and access to what is necessary.
- Apply role-based access, retention/deletion rules, auditability, and a data-protection impact assessment (DPIA) where profiling creates a likely high risk.
- Keep a person accountable for retention actions, support data-subject rights, and test for unfair segment outcomes.
- Use the model to prioritise helpful outreach and testing—not to make solely automated adverse decisions about customers.

This is a practical portfolio note, not legal advice.
